# DMS - Document Management System

یک سیستم مدیریت اسناد (DMS) کامل با استفاده از Flask، MySQL و SQLAlchemy

## ویژگی‌ها

- **احراز هویت**: ورود/خروج کاربران با رمزنگاری امن
- **مدیریت کاربران**: ادمین می‌تواند کاربران جدید ایجاد کند
- **مدیریت نقش‌ها**: تعریف نقش‌های مختلف و تعیین دسترسی‌ها
- **آپلود فایل**: آپلود فایل با فرمت‌های مختلف
- **تگ‌گذاری**: امکان افزودن تگ به فایل‌ها
- **پروژه‌ها**: دسته‌بندی فایل‌ها بر اساس پروژه
- **مجوز دسترسی**: تعیین اینکه کدام نقش‌ها می‌توانند فایل را ببینند
- **جستجوی پیشرفته**: جستجو بر اساس نام فایل، تگ، پروژه و بازه زمانی

## نصب و راه‌اندازی

### پیش‌نیازها

- Python 3.12+
- MySQL Server

### مراحل نصب

1. نصب وابستگی‌ها:
```bash
pip install flask flask-sqlalchemy flask-login pymysql cryptography python-dotenv werkzeug
```

2. تنظیمات دیتابیس:
   - یک دیتابیس MySQL با نام `dms_db` ایجاد کنید
   - فایل `config.py` را با اطلاعات دیتابیس خود ویرایش کنید

3. اجرای برنامه:
```bash
cd dms_app
python app.py
```

4. ورود به برنامه:
   - آدرس: http://localhost:5000
   - کاربر پیش‌فرض: `admin`
   - رمز عبور پیش‌فرض: `admin123`

## ساختار پروژه

```
dms_app/
├── app.py              # فایل اصلی برنامه
├── config.py           # تنظیمات
├── models.py           # مدل‌های دیتابیس
├── templates/          # قالب‌های HTML
│   ├── base.html
│   ├── login.html
│   ├── index.html
│   ├── upload.html
│   ├── file_details.html
│   ├── search.html
│   ├── projects.html
│   ├── tags.html
│   ├── users.html
│   └── roles.html
├── static/             # فایل‌های استاتیک
│   ├── css/
│   └── js/
└── uploads/            # فایل‌های آپلود شده
```

## مدل‌های دیتابیس

- **User**: کاربران سیستم
- **Role**: نقش‌های کاربران
- **File**: فایل‌های آپلود شده
- **Tag**: تگ‌ها برای دسته‌بندی فایل‌ها
- **Project**: پروژه‌ها برای سازماندهی فایل‌ها

## امکانات امنیتی

- رمزنگاری رمز عبور با Werkzeug
- کنترل دسترسی مبتنی بر نقش (RBAC)
- محافظت در برابر آپلود فایل‌های مخرب
- محدودیت حجم فایل (100MB)

## جستجوی پیشرفته

سیستم جستجو امکان فیلتر کردن بر اساس:
- نام فایل
- تگ‌ها (چند تگ همزمان)
- نام پروژه
- بازه تاریخ آپلود

را فراهم می‌کند.
